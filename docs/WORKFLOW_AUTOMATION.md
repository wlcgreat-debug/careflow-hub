### 🎬 유튜브 파이프라인

#### WF-001: 영상 → 전사 → 분석 → 썸네일 → 숏츠
```
트리거: 유튜브 링크 붙여넣기
소요시간: 자동 20-25분

[세영님]
    │
    ▼ 유튜브 링크 입력
    │
[영상 PD 🎥]
    ├─ 영상 다운로드
    ├─ 자동 전사 (Whisper)
    ├─ 타임스탬프별 정리
    ├─ 핵심 구간 마킹
    ├─ 제목 후보 3개 생성
    └─ 해시태그 추천
    │
    ▼ 전사 완료 알림
    │
┌───────────────────────────────────────┐
│              병렬 처리                 │
│                                       │
│  [썸네일 디자이너 🖼️]    [숏츠 PD 📱]  │
│      │                      │        │
│      ├─ 기존 썸네일         ├─ 숏츠 구간 │
│      │  스타일 분석         │  3개 추출  │
│      ├─ 제목 기반           ├─ 훅 문장   │
│      │  썸네일 컨셉         │  작성      │
│      ├─ 나노바나나프로      ├─ 숏츠별    │
│      │  이미지 생성         │  썸네일    │
│      └─ A/B 테스트용        │  컨셉 요청 │
│         변형 2개            └─ 스크립트  │
│                                       │
└───────────────────────────────────────┘
    │
    ▼
[AI 연동 🔗] (선택)
    └─ 전사 내용 → CareFlow 지식DB 저장
    │
    ▼
[세영님에게 최종 리포트]
    ├─ 📄 전사본 (타임스탬프 포함)
    ├─ 🎯 제목 후보 3개 + 추천 이유
    ├─ #️⃣ 해시태그 세트
    ├─ 🖼️ 썸네일 시안 3개 (메인 + 변형 2개)
    ├─ 📱 숏츠 기획안 3개 (각각 썸네일 컨셉 포함)
    └─ ✅ 세영님 검토/승인 요청
```

**실제 사용 예시:**
```
세영님: https://youtube.com/watch?v=xxxxx

[20분 후]

영상 PD: 전사 완료했습니다!

📄 전사본: [링크]
⏱️ 총 12분 43초, 핵심 구간 3개 마킹

🎯 제목 후보:
1. "허리 통증, 이 순서로 운동하세요" (검색 최적화)
2. "물리치료사가 알려주는 허리 운동 꿀팁" (클릭 유도)
3. "허리 아플 때 절대 하면 안 되는 운동" (호기심 유발)

💭 제 추천은 1번이에요 (🟡 확신도 80%)
   검색량 + 채널 톤 균형이 좋아요.
   세영님 생각은 어떠세요?

---

썸네일 디자이너: 썸네일 시안 준비했어요!

🖼️ 메인 썸네일:
   [이미지 미리보기]
   - 스타일: 치중진담 기존 톤 유지
   - 텍스트: "허리 통증 운동 순서"
   - 세영님 표정: 설명하는 포즈
   
🖼️ 변형 A (A/B 테스트용):
   [이미지 미리보기]
   - 더 강한 대비, 빨간색 강조
   
🖼️ 변형 B:
   [이미지 미리보기]
   - 미니멀, 텍스트 중심

📊 참고: 최근 치중진담 썸네일 중 CTR 상위 3개와
   유사한 레이아웃으로 제작했어요.

---

숏츠 PD: 숏츠 기획안 3개 준비했어요!

📱 숏츠 #1 (3:24-4:02)
   훅: "허리 아픈데 윗몸일으키기 하세요? 당장 멈추세요."
   썸네일 컨셉: X 표시 + 충격 표정
   예상 조회수: 높음 (🟡 논란성 훅)

📱 숏츠 #2 (7:15-7:58)  
   훅: "이 동작 하나면 허리 통증 50% 감소"
   썸네일 컨셉: 비포/애프터 느낌
   예상 조회수: 중간 (실용적)

📱 숏츠 #3 (10:30-11:15)
   훅: "물리치료사인 제가 매일 하는 허리 운동"
   썸네일 컨셉: 운동 동작 + 신뢰 뱃지
   예상 조회수: 중간 (신뢰성)

어떤 것부터 제작할까요?
```

#### WF-002: 댓글 수집 → 분석 → 콘텐츠 기획
```
트리거: "댓글 분석해줘" 또는 주 1회 자동
소요시간: 자동 10분

[댓글 관리자 💬]
    ├─ 최근 1주일 댓글 수집
    ├─ 카테고리 분류 (질문/감사/요청/불만)
    ├─ 콘텐츠 아이디어 될 댓글 추출
    └─ FAQ 업데이트
    │
    ▼
[유튜브 총괄 PD 🎬]
    ├─ 댓글 기반 콘텐츠 기획안 작성
    ├─ 키워드 검색량 확인
    └─ 우선순위 제안
    │
    ▼
[세영님에게 리포트]
    ├─ 📊 이번 주 댓글 요약 (감정 분석 포함)
    ├─ 💡 콘텐츠 아이디어 3개
    └─ ✅ 어떤 주제로 갈지 선택 요청
```

#### WF-002-1: 썸네일 제작 (독립 실행)
```
트리거: "썸네일 만들어줘: [제목/주제]" 또는 영상 링크
소요시간: 자동 5-10분

[썸네일 디자이너 🖼️]
    ├─ 제목/주제 분석
    ├─ 채널 (치중진담/CareFlow) 자동 판별
    ├─ 기존 썸네일 포트폴리오에서 유사 스타일 참조
    ├─ 나노바나나프로로 이미지 생성
    │   ├─ 메인 시안 1개
    │   └─ A/B 테스트용 변형 2개
    └─ 포트폴리오에 자동 저장
    │
    ▼
[세영님에게 결과]
    ├─ 🖼️ 썸네일 시안 3개
    ├─ 📊 참조한 기존 썸네일 (CTR 높았던 것)
    ├─ 💭 추천 시안 + 이유
    └─ ✅ 선택/수정 요청
```

**썸네일 디자이너 추가 기능:**

```
📁 포트폴리오 관리 명령어:

"포트폴리오 보여줘"
→ 전체 썸네일 아카이브 (CTR 순 정렬)

"치중진담 스타일 분석해줘"  
→ 치중진담 채널 썸네일 패턴 리포트

"CTR 높은 썸네일 공통점 뭐야?"
→ 성과 분석 인사이트

"이 스타일로 템플릿 만들어줘"
→ 재사용 가능한 템플릿 저장

"썸네일 A/B 테스트 결과"
→ 변형별 성과 비교
```

### ✍️ 콘텐츠 파이프라인

#### WF-003: 주제 → 칼럼 초안 → 검토 → 발행
```
트리거: "칼럼 써줘: [주제]"
소요시간: 자동 20분 + 세영님 검토

[글쓰기 AI ✍️]
    ├─ 주제 관련 세영님 기존 글 분석
    └─ @기능재활 전문가에게 전문 내용 요청
    │
    ▼
[기능재활 전문가 🏃]
    ├─ 주제 관련 핵심 포인트 정리
    ├─ 근거 자료 (논문/가이드라인) 제시
    └─ 주의사항/면책 조항 제안
    │
    ▼
[글쓰기 AI ✍️]
    ├─ 세영님 스타일로 초안 작성
    ├─ 확신도 낮은 부분 표시
    └─ 검토 필요 포인트 정리
    │
    ▼
[세영님 검토]
    ├─ 수정 지시 → 반영 → 재검토
    └─ 승인 → 발행 준비
```

### 워크플로우 엔진

```python
class WorkflowEngine:
    """워크플로우 실행 엔진"""
    
    def __init__(self, agent_hub):
        self.agent_hub = agent_hub
        self.running_workflows: dict[str, WorkflowInstance] = {}
        
    async def start_workflow(
        self, 
        workflow: Workflow, 
        input_data: dict
    ) -> str:
        """워크플로우 시작"""
        instance_id = f"wf-{datetime.now().timestamp()}"
        
        instance = WorkflowInstance(
            id=instance_id,
            workflow=workflow,
            input_data=input_data,
            status=WorkflowStatus.RUNNING,
            current_step=0,
        )
        
        self.running_workflows[instance_id] = instance
        
        # 비동기로 실행 시작
        asyncio.create_task(self._run_workflow(instance))
        
        return instance_id
    
    async def _run_workflow(self, instance: WorkflowInstance):
        """워크플로우 실행"""
        try:
            for step in instance.workflow.steps:
                # 에이전트 호출
                agent = self.agent_hub.get_agent(step.agent_id)
                result = await step.action(agent, instance.data)
                
                # 결과 저장
                instance.data[step.name] = result
                instance.current_step += 1
                
                # 승인 필요시 대기
                if step.requires_approval:
                    instance.status = WorkflowStatus.WAITING_APPROVAL
                    await self._notify_user(instance, "검토가 필요합니다")
                    await self._wait_for_approval(instance)
                
                # 진행 상황 알림
                await self._notify_progress(instance)
            
            instance.status = WorkflowStatus.COMPLETED
            await self._notify_user(instance, "완료되었습니다!")
            
        except Exception as e:
            instance.status = WorkflowStatus.FAILED
            await self._notify_user(instance, f"오류 발생: {e}")
```

### 🔄 제3원칙: 자동화 우선 (Automation First)

```
반복되는 일 = 자동화 대상
세영님이 같은 일을 두 번 하면 = 워크플로우로 만들어야 한다

목표: 세영님은 "판단"만, 나머지는 에이전트가
```

**자동화 판단 기준:**
1. 같은 패턴의 작업이 3회 이상 반복되는가?
2. 단계가 명확하게 정의되는가?
3. 에이전트가 처리 가능한 작업인가?

**자동화 수준:**
```
Level 1: 수동 트리거 (세영님이 "실행" 클릭)
Level 2: 조건 트리거 (특정 조건 만족시 자동)
Level 3: 예약 트리거 (정해진 시간에 자동)
Level 4: 완전 자동 (입력부터 출력까지)
```
