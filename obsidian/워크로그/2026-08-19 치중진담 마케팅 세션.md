# 2026-08-19 치중진담 마케팅 세션

AI 노출(GEO) 질문에서 출발해 치중진담 유튜브·블로그 마케팅 전략, 자동화 프로그램 구상, 유튜브 데이터 수집 인프라 구축까지 진행한 세션. 전략 결론은 [[치중진담 마케팅 전략]], API 인프라는 [[YouTube API 연동]] 참고.

## 오늘 결정된 것

1. **GEO(AI 검색 노출) 기본 방향 수립** — 네이버 블로그는 해외 AI 크롤러가 못 읽으므로, AI에게 보이는 유일한 텍스트 채널은 티스토리(장기적으로 자체 도메인). 상세는 [[치중진담 마케팅 전략#GEO]].
2. **채널 자산 현황 확정** — 잠실 한빛: 네이버 블로그 있음(원본 칼럼 게재처) / 여수 바로본: 네이버 블로그 없음(신설 권장, 저경쟁 시장이라 ROI 최고) / 티스토리: 공통 블로그(현재는 요약본 게재).
3. **콘텐츠 흐름 재정의** — 네이버 원본 → 티스토리는 "요약"이 아니라 **GEO 재구성**(질문형 제목 + 직답 + FAQ)으로. 칼럼당 쇼츠 대본 1개 → **앵글별 3~5개**로 확대(공감 훅 / 오해 깨기 / 실습 / 케이스 스토리 / Q&A).
4. **AI 마케팅 자동화 방향** — 네이버·티스토리는 발행 API가 없어 완전 자동 발행은 불가(저품질·약관 리스크). 대신 "1원본 → N파생물 공장 + 검수 게이트 + 복붙 패키지" 구조로. 기존 Claude 스킬(content-studio, shorts-studio, column-auditor, thumbnail)이 부품 역할. 옵션1(Claude Routine) 먼저 검증 후 옵션2(careflow-hub 웹앱)로 승격하는 순서 합의.
5. **성과 분석 착수** — 치중진담 채널 쇼츠 조회수 상위권 + 게시글 상위권 분석 요청받음. 이를 위해 YouTube Data API 키 발급·연동 진행.
