# 치중진담 마케팅 전략

Team CareFlow(치중진담) 유튜브·블로그 마케팅의 기준 문서. 2026-08-19 세션에서 수립 (→ [[2026-08-19 치중진담 마케팅 세션]]).

## 목표 2층 구조

| 층 | 목표 | 주 무기 |
|---|---|---|
| 로컬 | 잠실 한빛·여수 바로본 내원 환자 유입 | 네이버 블로그 + 플레이스 |
| 브랜드 | "기능재활 = Team CareFlow" 전국 인지 | 유튜브 + 티스토리(GEO) |

콘텐츠마다 어느 층인지 정하고 제목·키워드·CTA를 맞춘다.

## 채널 역할

- **한빛 네이버 블로그 (잠실)**: 지역+증상+치료 롱테일 키워드 ("잠실 도수치료", 질문형 키워드). 대형 키워드는 포기. 플레이스 연동 필수.
- **바로본 네이버 블로그 (여수)**: **신설 권장 — 가성비 최고 카드.** 여수는 저경쟁이라 "여수 도수치료" 류 키워드 수개월 내 상위 노출 현실적. 선행 과제: 플레이스 정비(사진·진료안내·리뷰 QR).
- **티스토리 (공통)**: GEO 본진. 요약본이 아니라 **재구성본** — 질문형 제목 + 첫 문단 직답 + FAQ 2~3개 + 원문·유튜브 링크. 스킨 HTML에 저자 프로필 + JSON-LD 스키마 삽입 가능. 장기적으로 자체 도메인으로 이전.
- **유튜브**: 쇼츠 = 도달(주 3~5), 롱폼 = 신뢰·전환(주 1, case report 시리즈). 모든 영상에 고정댓글(예약+블로그 링크). 교정 자막 업로드(유튜브 검색 + AI 인용 양쪽에 효과).

## GEO (AI 검색 노출) 핵심

- AI(ChatGPT·Perplexity·구글 AI)가 읽을 수 있는 건 **티스토리/자체 도메인뿐** — 네이버 블로그는 AI에게 존재하지 않음.
- 인용되는 글의 형태: 질문형 제목, 첫 2~3문장 직답, 명시적 정의문("반사적 안정화란 ~이다"), 수치·근거·출처, FAQ 블록.
- CareFlow 고유 용어(반사적 안정화, 복압 실린더 등)는 **용어집 페이지**로 개념 출처 선점.
- 신뢰 신호(의료 YMYL): 의사 실명 저자 표기 + 약력 프로필, 제3자 언급(기고·인터뷰) 확보.
- 측정: 월 1회 동일 질문 세트를 AI들에 물어 브랜드 언급 기록, 애널리틱스에서 chatgpt.com/perplexity.ai 리퍼러 추적.

## 콘텐츠 흐름 (1원본 → N파생물)

```
네이버 원본 칼럼 (한빛 or 바로본, 원장 검수 완료)
 ├─ 티스토리 GEO 재구성본 (700~1,200자, 자립형)
 ├─ 쇼츠 대본 3~5개 (앵글: 공감 훅 / 오해 깨기 / 실습 / 케이스 / Q&A)
 │    └─ 제작 병목 시 1~2개만 영상화, 나머지는 인스타·커뮤니티 게시물로
 ├─ 인스타 캡션 + 이미지 프롬프트
 ├─ 유튜브 커뮤니티 게시판판
 └─ 썸네일
```

- 같은 글 복붙 금지 (네이버 유사문서 필터). 채널별 리라이트.
- 쇼츠는 편당 도달이 복권 → **시도 수가 성과**. 칼럼당 1개는 낭비.

## 자동화 프로그램 방침

- 완전 자동 발행 **불가/금지**: 네이버·티스토리 발행 API 없음, 브라우저 자동화는 저품질 위험. 원장 검수는 제거하면 안 되는 단계(의료광고법).
- 구조: 파생물 생성 → 정합성·의료광고 표현 게이트 → 채널별 복사 버튼 HTML 패키지 → 사람이 승인·붙여넣기(주 30분 이내 목표).
- 부품은 기존 스킬 재사용: content-studio, shorts-studio, column-auditor, medical-writing-safeguards, thumbnail.
- 순서: **옵션1** Claude Routine으로 주간 파이프라인 검증 → **옵션2** careflow-hub 웹앱(검수 UI + 지표 대시보드)으로 승격.
- 자동화 금지 항목: 자동 발행, 검수 생략, 댓글 자동 게시(초안 생성까지만).

## 우선순위

1. 바로본 플레이스 정비 + 네이버 블로그 신설
2. 티스토리 GEO 정비 (저자 프로필·스키마·카테고리)
3. 주간 케이던스 가동 (원문 1편 → 파생물 패키지)
4. 성과 분석 기반 앵글 조정 (→ 쇼츠/게시글 상위권 분석)
5. 자체 도메인 정적 사이트 (careflow-hub 기반, 장기)
